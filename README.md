# mascot

Claude Code が考えている間、スピナーの左でマスコットが動くプラグイン。`~/.claude/mascots/` に置いた `.mascot` ファイルから、ターンごとにランダムに 1 体が出て、ターンが終わると消える。

plugin 自体にマスコットは入っていない。`.mascot` ファイルを 1 つ置くと動き出す。

## インストール

```
claude plugin marketplace add ~/code/claude-mascot
claude plugin install mascot@mascot-marketplace
```

## マスコットの追加

`~/.claude/mascots/` に `好きな名前.mascot` を置く。再起動は不要で、ターンが終わるたびに読み直して次に出る 1 体を決めるので、その次のターンから候補に入る。複数置けばターンごとに入れ替わる。読めないファイルはスキップされ、理由が `/debug` のログに出る。

マスコットのデータはこのリポジトリには入っていない。受け取った `.mascot` ファイルを置く。

```
mkdir -p ~/.claude/mascots
cp 受け取った.mascot ~/.claude/mascots/
```

### ファイルの書き方

```
# 先頭の # はコメント
color: #ffffff        # 本体の色（省略するとターンごとに変わる色になる）
overlay: #eb99b1      # [overlay] の色
frame-ms: 120         # 1 フレームの長さ（省略時 120）

[still]
  ▐▛███▜▌
 ▝▜█████▛▘
   ▘▘ ▝▝

[frame]
 ▐▛███▜▌
▝▜█████▛▘
  ▘▘ ▝▝

[frame x6]
   ▐▛███▜▌
  ▝▜█████▛▘
    ▘▘ ▝▝

[overlay]

  ▄▄     ▄▄
```

- `[still]` は必須。何も走っていないときの姿で、行数はこれが基準になる。
- `[frame]` は動きの 1 コマ。書いた順に回り、最後まで行くと最初に戻る。`[frame x6]` と書くとそのコマを 6 回分（約 0.7 秒）保つ。`[frame]` が 1 つもなければ `[still]` のまま止まっている。
- `[overlay]` は全コマの上に `overlay` の色で重ねるセル。ほっぺや首輪のように色を変えたい部分を、本体と同じ位置に描く。本体側はその位置を空けておく。
- 幅はいちばん長い行に揃う。`[frame]` の行数は `[still]` と同じでないとエラー。`[overlay]` は下が空なら途中で終わってよい。

### 描き方のコツ

ターミナルのセルは縦長（幅 1 : 高さ 2）なので、ドット絵をそのまま写すと縦に伸びる。

- 2×2 ドットを 1 セルに詰める quadrant（`▘▝▖▗▌▐▀▄█`）だと、ドットは縦長になる。
- 2×4 ドットを 1 セルに詰める octant（Unicode 16 の Symbols for Legacy Computing Supplement）だと、ドットが正方形になり、ドット絵がそのまま写せる。Ghostty 1.1 以降など、octant を描ける端末が必要。

octant の例として、正面猫の `.mascot` は 40×40 ドットの元絵を 20 列 × 10 行に写している。
